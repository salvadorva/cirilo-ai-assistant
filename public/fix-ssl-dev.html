🔧 Configurar SSL para PWA - Desarrollo

⚠️ Problema Detectado

El Service Worker no puede registrarse debido a un error de certificado SSL. Esto es común en desarrollo local.

🚀 Solución Rápida

Para probar la PWA en desarrollo, puedes:

Opción 1: Usar HTTP (Limitado)

⚠️ Algunas funciones PWA no funcionarán completamente con HTTP

Opción 2: Aceptar Certificado SSL

  1. Visita: https://asistente.its
  2. Haz clic en "Avanzado" o "Advanced"
  3. Haz clic en "Continuar a asistente.its (no seguro)"
  4. Una vez aceptado, regresa a probar la PWA

🔧 Configuración Permanente (Opcional)

Para una solución permanente en desarrollo:

# Instalar certificado en el sistema
sudo cp /path/to/mkcert/rootCA.pem /usr/local/share/ca-certificates/mkcert-root.crt
sudo update-ca-certificates

O en Chrome:

  1. Ve a chrome://settings/certificates
  2. Pestaña "Authorities"
  3. Importa el certificado root de mkcert

✅ Verificar Configuración

Una vez configurado el SSL, prueba la PWA:

📱 Después de Configurar SSL

Una vez que el certificado SSL esté funcionando:

  • ✅ Service Worker se registrará correctamente
  • ✅ Aparecerá el botón "Instalar App" en Chrome
  • ✅ La PWA funcionará completamente offline
  • ✅ Podrás instalar la app como aplicación nativa
