# Imágenes de Enemigos - Modo Supervivencia

Este directorio contiene las imágenes de los enemigos para el Modo Supervivencia de TypeMaster AI.

## Archivos de Imágenes Requeridos:

### Enemigos Básicos (96x96px):
- **slime.png** - Enemigo básico nivel 1-5 (Verde gelatinoso, amigable)
- **goblin.png** - Enemigo básico nivel 6-10 (Pequeño guerrero verde)
- **skeleton.png** - Enemigo intermedio nivel 11-15 (Esqueleto guerrero)
- **orc.png** - Enemigo intermedio nivel 16-20 (Guerrero orc fuerte)

### Enemigos Avanzados (128x128px):
- **wizard.png** - Enemigo mágico nivel 21-25 (Mago con túnica)
- **dragon.png** - Enemigo fuerte nivel 26-30 (Dragón pequeño)
- **demon.png** - Enemigo élite nivel 31+ (Demonio oscuro)

### Jefe Final (256x256px):
- **boss-tyrant.png** - Jefe final (Rey tirano, imponente)

## Especificaciones:
- Formato: PNG con transparencia
- Estilo: Pixel art o cartoon amigable
- Colores: Vibrantes pero no agresivos
- Diseño: Apropiado para todas las edades

## Uso:
Estas imágenes se muestran en el campo de batalla del Modo Supervivencia,
apareciendo cuando el jugador debe escribir las palabras para derrotar enemigos.

## Animaciones CSS:
Las imágenes se animan automáticamente con:
- Efecto de respiración (breathing)
- Efecto de daño (damage) cuando son golpeadas
- Efecto de entrada (enemy-appear) al aparecer
- Efecto de derrota (enemy-defeat) al ser derrotadas
