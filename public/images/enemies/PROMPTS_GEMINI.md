## 🔧 INSTRUCCIONES DE USO

### Para cada imagen:

1. **Copia el prompt** del enemigo que quieres generar
2. **Abre Gemini** (bard.google.com o gemini.google.com)
3. **Pega el prompt** y presiona Enter
4. **Espera la generación** (puede tomar 30-60 segundos)
5. **Descarga la imagen** (clic derecho → Guardar imagen)
6. **Renombra el archivo** con el nombre exacto especificado
7. **Sube el archivo** a `/var/www/asistente/public/images/enemies/`

### Verificación rápida:
```bash
cd /var/www/asistente/public/images/enemies/
ls -la *.png
```

### Si Gemini no puede generar imágenes:
- Prueba con **DALL-E 3** (ChatGPT Plus)
- Usa **Bing Image Creator** (gratis)
- Busca en **OpenGameArt.org** (recursos gratuitos)
